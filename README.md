# 🎓 ISI Chatbot

An AI-powered chatbot designed to help students and prospective students access information about the **Institut Supérieur d'Informatique (ISI)**.

The chatbot provides quick and accessible answers about academic programs, student services, clubs, campus resources, and other useful information related to ISI.

## 📌 Project Overview

Students and prospective students often need to search through different sources to find information about academic programs, university services, clubs, and campus life.

The goal of this project is to provide a **conversational interface** that allows users to ask questions naturally and obtain relevant information without manually searching through multiple sources.

The chatbot was developed using **Botpress** and combines a dedicated knowledge base containing ISI documentation with access to the **official ISI website** to provide information that can be kept up to date.

## 🧠 Knowledge & Information Sources

The chatbot relies on two complementary information sources:

### 📚 ISI Knowledge Base

A dedicated knowledge base was created using **prepared PDF documents containing information about ISI**, including academic programs, student services, clubs, and other university-related information.

These documents provide a structured source of information that the chatbot can use to answer frequently asked questions.

### 🌐 Official ISI Website

The chatbot can also access the **official ISI website** to retrieve more recent information.

This provides an additional source for information that may change over time, helping the chatbot provide more up-to-date answers rather than relying exclusively on static documents.

## ⚙️ How It Works

The chatbot combines **document-based knowledge retrieval** with access to the official ISI website.

1. The user asks a question through the chatbot.
2. The chatbot analyzes the user's request.
3. Relevant information is retrieved from the ISI knowledge base when applicable.
4. When more recent or website-based information is needed, the chatbot can access the official ISI website.
5. The AI generates a response based on the available information.
6. The user receives the answer through the conversational interface.
